Kebijakan Privasi

Kartu Matematika

Terakhir diperbarui: 28 Oktober 2026

1. Pendahuluan

Kartu Matematika adalah aplikasi edukasi matematika berbasis permainan untuk membantu pengguna berlatih berhitung secara interaktif.

2. Data yang Disimpan

Aplikasi menyimpan data permainan secara lokal pada perangkat, seperti progres, skor, statistik, pencapaian, dan pengaturan aplikasi, sesuai fitur yang digunakan.

3. Pengumpulan dan Pembagian Data

Berdasarkan implementasi yang telah diverifikasi, aplikasi beroperasi secara offline dan tidak mengirimkan data permainan ke server eksternal. Aplikasi tidak membagikan data tersebut kepada pihak ketiga.

4. Penyimpanan dan Penghapusan Data

Data permainan disimpan pada perangkat pengguna. Data dapat terhapus ketika data aplikasi dihapus atau aplikasi diuninstal. Perilaku pencadangan perangkat dapat berbeda-beda.

5. Keamanan

Data permainan dikelola secara lokal oleh aplikasi. Pengguna disarankan menjaga keamanan perangkatnya.

6. Privasi Anak

Aplikasi ditujukan kepada kelompok usia yang dinyatakan dalam pengaturan audiens Google Play. Pengelolaan data tetap mengikuti praktik yang dijelaskan dalam kebijakan ini.

7. Perubahan Kebijakan

Kebijakan ini dapat diperbarui apabila fitur atau praktik pengelolaan data aplikasi berubah.
